## 🛡️ The Encyclopedia of Cybersecurity

**HackTricks Security Toolkit** is not just a repository; it's a complete, community-driven encyclopedia and toolkit for offensive and defensive cybersecurity. Whether you are an aspiring penetration tester, a seasoned Red Teamer, or a system administrator looking to harden your network, HackTricks provides the methodologies, payloads, and scripts you need.

This toolkit aggregates years of industry experience. It covers everything from Active Directory exploitation and privilege escalation to web application hacking and cloud security. Instead of digging through hundreds of blogs and outdated forums, you get a centralized, constantly updated platform of verified techniques. It includes custom scripts, cheat sheets, and automated tools that can be deployed directly in a lab or a sanctioned pentest environment.

> 💡 **Why use HackTricks?** Because in cybersecurity, knowledge is power. Stay ahead of the attackers by learning how they think, how they operate, and exactly what tools they use.

## ❓ Frequently Asked Questions

<details>
<summary><b>Is this legal to use?</b></summary>

Yes, the **knowledge** is legal and protected under free speech. However, **using** these techniques against systems you do not own or have explicit written permission to test is illegal and strictly prohibited. This toolkit is for educational and authorized security testing only.
</details>

<details>
<summary><b>Do I need to be an expert to use this?</b></summary>

The documentation starts with basic concepts and progresses to advanced exploitation. It is heavily used by beginners preparing for certifications like OSCP, as well as seasoned professionals.
</details>

<details>
<summary><b>Does it include the actual hacking tools?</b></summary>

HackTricks provides the payloads, commands, and methodologies. It often links to open-source tools (like Nmap, Metasploit, or custom GitHub repos) that you can install to execute the techniques.
</details>

<details>
<summary><b>Who maintains this repository?</b></summary>

It is maintained by a global community of security researchers. Anyone can submit a Pull Request with new payloads, updated commands, or new vulnerabilities.
</details>

<details>
<summary><b>How do I report a bug?</b></summary>

Open an issue on the GitHub repository if you find a typo, a broken command, or if you want to suggest a new technique.
</details>
